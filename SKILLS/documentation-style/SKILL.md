name: Documentation style
description: Use before writing or editing any governed prose (a docs page, README text, file header, doc comment, config or script comment, or test name). Holds the binding text rules.
---

Read `AGENT-INSTRUCTIONS/BUILDING/DOCUMENTATION-STYLE-GUIDE.md` before writing prose. It is
binding even when the change does not touch `docs/`.

The guide owns content rules, writing rules, terminology, Markdown shape, code documentation and
the closing report. Run its self-check on what you wrote, and do not invent a house style where
the guide already names one.
