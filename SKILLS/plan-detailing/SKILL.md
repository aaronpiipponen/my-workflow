Read `AGENT-INSTRUCTIONS/PLANNING/PLAN-PHASE-DETAILING.md` before detailing a phase.

It owns the detail bar, the no-invention protocol, gate levels and the closing survey. The
shape itself is `PLANNING/phase-template.md`; create the file with the `phase_new` tool rather
than retyping the skeleton, then fill every placeholder from current authoritative files. A
symbol, signature or path you did not read does not belong in the document.
