The guide below shapes the root README; the documentation style guide still owns its wording.
Load the `documentation-style` skill too, and list every departure from it in the closing report.
The root README shows screenshots and an architecture diagram when they help, and a small
repository may have neither. Link the documentation once for the features section, not after every
feature. The release's overall visual pass covers whatever images it has, along with every other
visual the repository shows.
